Политика конфиденциальности

Эта политика описывает личную настройку Yandex Backup для резервного копирования файлов с помощью rclone.

Доступ к данным и их использование

rclone использует содержимое файлов, их имена, размеры, даты изменения и структуру папок для копирования и проверки резервных копий. Google Drive API используется для просмотра целевых папок, загрузки файлов и обновления копий. Данные используются только для резервного копирования по командам владельца.

Хранение и передача

Исходные файлы хранятся на Яндекс Диске, резервные копии — в Google Drive владельца. Передача выполняется через его компьютер. OAuth-токены и параметры подключения хранятся в локальном конфигурационном файле rclone; журналы могут содержать имена и пути файлов. Владелец отвечает за защиту компьютера, конфигурации и журналов.

Данные обрабатываются соответствующими облачными провайдерами при выполнении операций. Эта личная настройка не продаёт данные, не использует их для рекламы или обучения моделей ИИ и не предоставляет их другим пользователям.

Отзыв доступа и удаление

Владелец может остановить задания резервного копирования, отозвать разрешения в настройках Google-аккаунта и Яндекса и удалить локальную конфигурацию rclone. Отзыв доступа не удаляет ранее созданные резервные копии: их можно удалить отдельно в Google Drive.

Сайт

На страницах проекта нет форм, аналитических скриптов или собственной системы cookies. Страницы размещены на GitHub Pages; техническая обработка запросов хостингом регулируется политикой конфиденциальности GitHub.

Использование Google API

Использование информации, полученной через Google API, должно соответствовать Google API Services User Data Policy, включая требования Limited Use. Доступ применяется исключительно для описанного личного резервного копирования.
